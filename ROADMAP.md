# Noor Scanner PC — Seven-Session Upgrade Roadmap

This is the planned order for the seven scheduled 10:00 AM Algeria-time sessions. Every session must inspect the current branch, make one focused improvement, run the available tests/build, and update the daily log. Planned items are not claimed as shipped until committed and verified.

1. **Bring documents in (shipped 2026-10-02):** import local photos, images, and PDFs into a page workspace, list imported pages in file-picker order, and export them as one PDF. Thumbnails, page reordering, and removal remain in step 2.
2. **Build the page queue (shipped 2026-10-03):** preview imported pages with thumbnails, move the selected page earlier or later, remove pages, and export in the current queue order.
3. **Clean up scans (in progress; rotation shipped 2026-10-04, Document enhancement shipped 2026-10-05, symmetric crop presets shipped 2026-10-06):** rotate pages; apply/reset NAPS2 Document correction; and trim 2%, 5%, or 10% from each current page edge. Resetting crop preserves other transforms. Freehand crop selection and photo-specific adjustment remain planned.
4. **Searchable PDFs (implemented on staging 2026-10-07; Windows CI verified, real-model quality check pending):** opt-in local OCR for scanned and workspace PDFs; English, French, or Arabic selection; clear preflight messages for missing language data/engine; abort and remove temporary output if OCR errors or times out. Language model files are intentionally not bundled. Validate actual text recognition with installed models and representative Windows scans before release.
5. **Reusable scan settings:** save and reuse resolution, source, color, and page-size preferences.
6. **Document organization:** improve naming, recent output access, error recovery, and keyboard/accessibility behavior.
7. **Release-quality improvement and audit (audit performed 2026-10-07; release deferred):** the OCR improvement is implemented on the staging branch; tests and Windows build pass; no vulnerable NuGet packages were reported by the current sources; privacy and third-party notices were reviewed; a release-notes draft is prepared. Release is not recommended yet: step 5 (reusable scan settings), step 6 (document organization), physical scanner validation, real-model OCR validation, and an application source license are still outstanding. Do not make the repository public, merge to the default branch, or publish a release without first showing the exact final contents and target for the user's confirmation.
